# EBRF Reasoning Assistant 1.0

Website preparation for the Evidence-Based Reasoning Framework (EBRF), published by Ferat Sahin.

## Status

- The ChatGPT plugin remains private; public submission is in preparation.
- Website source is prepared here. GitHub Pages still needs to be enabled.
- `terms.html` contains terms approved by Ferat Sahin on October 21, 2026. Public website URLs still need deployment and verification.
- This repository contains the project website, not the full framework source or an installable plugin archive.

## Pages

| File | Purpose |
| --- | --- |
| index.html | Overview, features, examples, and framework description |
| support.html | Support through GitHub Issues |
| privacy.html | Plugin, website, and public support data practices |
| terms.html | Approved terms of use |

## Review decisions

Publisher confirmed support through GitHub and no independent collection of plugin usage or conversation data outside ChatGPT. Support submissions are a distinct, voluntary public disclosure on GitHub.

Approved terms: no publisher charge; no guarantee of AI accuracy; independent verification and appropriate professional input for consequential decisions; no guaranteed support response time; no separate redistribution license granted. Publisher approved these choices on October 21, 2026.

No analytics, scripts, external fonts, contact forms, accounts, or payments are included in this website.

## Enable GitHub Pages

In repository Settings → Pages, set Source to **Deploy from a branch**, select **main**, select **/(root)**, then Save.

Expected default address after deployment: https://feseee.github.io/EBRF/ (not a verified live URL yet).

GitHub guidance: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Local preview

Serve this folder with any static HTTP server, for example `python3 -m http.server 8000`, and open http://localhost:8000.
