Privacy policy

Prepared October 21, 2026 · EBRF Reasoning Assistant 1.0

Scope

This page describes the data practices of Ferat Sahin, publisher of EBRF Reasoning Assistant 1.0, for the plugin and this project website. ChatGPT and GitHub operate separate services with their own privacy policies.

Plugin conversations

EBRF 1.0 is a package of reasoning instructions and reference documents used within ChatGPT. It has no publisher-operated external server or database configured. The publisher does not independently collect, receive, store, sell, or share your ChatGPT conversations or plugin usage data through this plugin.

This does not mean that ChatGPT does not process or retain information. Your use of ChatGPT, and any other tools you choose to use with it, remains subject to the relevant provider's policies and your account settings.

This website

The website uses static pages. It includes no publisher-added analytics, advertising trackers, cookies, contact forms, or user accounts. GitHub hosts the website when GitHub Pages is enabled and may process technical information under its own policies.

Support through GitHub Issues

If you submit an issue, your GitHub username, report, attachments, and replies are visible on the public repository. The publisher can read and respond to information you voluntarily post there to address your request. Avoid posting personal or confidential information, credentials, or private conversation transcripts.

Issue content and its history are stored by GitHub and may remain public until edited or removed under GitHub's controls. The project sets no separate automatic deletion period. Use GitHub's editing, deletion, and support controls for information you post. Requests about project-managed content can be raised through the support page without repeating sensitive information.
