Help & feedback

Support through GitHub.

Report a problem, ask a question, or suggest an improvement to EBRF Reasoning Assistant 1.0.

Open a support issueBrowse existing issues

What to include

  • A short description of your question or problem.
  • The framework version you used, such as EBRF 1.0.
  • Steps to reproduce it and what you expected to happen.
  • A minimal, anonymized example if it helps explain the issue.

Keep your report safe to share

GitHub Issues are public and require a GitHub account to post. Do not include passwords, API keys, personal records, confidential research, or private conversation transcripts. Share only the minimum non-sensitive information needed to describe the issue.

Maintainer

Ferat Sahin maintains this project. There is no guaranteed support response time. GitHub Issues are the support channel for this plugin, not an emergency or professional advisory service.

For details about support information, see the privacy policy.
